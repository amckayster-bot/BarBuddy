# BarBuddy
# the mckaysters IOS app
Finding good nightlife in Chicago today means trusting word-of-mouth or a stale Google top-10 list — no idea what's happening tonight, or if the place even has a pool table. This app fixes that: crowd-verified venue details, real-time events, and recommendations that get smarter every time you check in and rate a spot. Nightlife discovery, verified by the people actually going out.
